# Aurora Dashboard

> Multi-chain portfolio tracker

## Features

- Asset overview
- P&L tracking
- Gas optimizer
- DeFi positions

## Tech Stack

- Frontend: HTML5, CSS3, JavaScript
- Blockchain: Solidity, Rust, Web3.js
- AI: MiMo V2 Flash, Claude Code

## Installation

```bash
git clone https://github.com/bimolasi/aurora-dashboard.git
cd aurora-dashboard
npm install
npm run dev
```
